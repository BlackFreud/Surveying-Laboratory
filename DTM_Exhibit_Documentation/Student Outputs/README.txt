STUDENT OUTPUTS
===============

This folder collects completed Laboratory Activity Sheets from students who
have used the DTM Simulator.

Laboratory_Activity_Sheet_TEMPLATE.docx is the blank template to distribute
to students. As students complete the activity, save each submission here
using a clear naming pattern, for example:

  2026-09-15_Dela-Cruz-Juan_Activity-Sheet.docx

This folder is intentionally empty of actual submissions until students have
completed the activity — no sample or placeholder data has been included.
